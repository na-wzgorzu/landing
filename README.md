Do wygenerowania builda nalezy zrobić

```
npm run build
```

Następnie Podmienić zawartość pliku /cennik/index.html, na tą z serwera.
Przy podmianie należy podmienić tylko treść strony (bez headera i footera).
Następnie nalezy skopiować blok kodu <styles></styles> z sekcji <head></head> i wkleić do nowo wygenerowanego pliku /cennik/index.html
Następnie usunać wszystkie tagi <scripts> na końcku wygenerowanego pliku.
